# RC Training Aircraft

## Overview

This project is a foam board RC training aircraft designed and built for learning aerodynamics, aircraft construction, electronics integration, and radio-controlled flight operations.

## Components

* 5 mm Foam Board Airframe
* FlySky FS-i6X 2.4 GHz 10-Channel Transmitter
* FlySky FS-iA10B Receiver
* Skywalker 30A ESC
* DJI 2212 920KV Brushless Motor
* 4 × SG90 Servo Motors
* 10×4.5 Propeller

## Features

* Lightweight foam board construction
* Stable flight characteristics for training purposes
* Aileron, Elevator, Rudder, and Throttle control
* Easy maintenance and repair
* Cost-effective design
